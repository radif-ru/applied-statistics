## Задача

Два ноутбука с прикладными задачами. В первом для каждой ситуации подбирается
подходящий критерий: настройка дозатора, сравнение прочности материалов, эффект
лекарства, выбор корма, A/B-тест конверсии. Во втором на выборке из 30 человек
изучаются связи между признаками и строятся регрессионные модели — от парной
регрессии до множественной с диагностикой остатков. По каждой задаче выводятся
численные результаты и делается практический вывод.

## Принципы реализации

- Структура ноутбуков и условия задач сохранены из исходных шаблонов: заполнены
  только ячейки решений и выводов.
- Используются только разрешённые библиотеки: в первом ноутбуке — numpy, scipy,
  statsmodels, matplotlib; во втором к ним добавлен pandas.
- Тест выбирается по проверке предпосылок: нормальность (Шапиро-Уилк),
  равенство дисперсий (Левен, F-тест), гомоскедастичность (Бройш-Пэган),
  мультиколлинеарность (VIF). Выбор и вывод фиксируются в тексте задачи.
- Случайность воспроизводима: в первом ноутбуке `np.random.seed(42)` перед
  бутстрэпом, во втором — заданный в шаблоне `np.random.seed(28)`.
- Ноутбуки сохраняются вместе с выводом, но без метаданных времени выполнения;
  CI выполняет их заново и сравнивает вывод с сохранённым.
- Ноутбук находит данные рядом с собой, в `data/` или скачивает по ссылке из
  репозитория, поэтому одинаково запускается локально и в Colab.

## Задачи и методы

| 7 | — | RMSE против стандартного отклонения целевой переменной |
| 8 | — | Градиентный спуск со свободным членом и сравнение с МНК |
| 9 | — | Перцентильный бутстрэп-интервал для корреляции |

## Запуск

Нужен [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.record_timing=False notebooks/*.ipynb
```

Ноутбуки открываются в любом Jupyter-окружении или в Colab по ссылкам выше.

## Проверки

```bash
uv run ruff check .
uv run ruff format --check .
uv run python -m unittest discover -s tests -v
```

Тесты выполняют каждый ноутбук с нуля и проверяют:

- ячейки выполнены по порядку, ошибок и предупреждений нет;
- сохранённый вывод совпадает с выводом нового запуска;
- у каждой задачи есть вывод, заглушек шаблона не осталось;
- ключевые результаты совпадают с эталонными.
